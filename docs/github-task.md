# GitHub issue: Implement CV Analysis and Job Recommendation Module

## Goal
Help candidates identify skills, discover development gaps and find relevant jobs.

## Acceptance criteria
- [ ] Candidate can submit plain-text CV content.
- [ ] Known skills are extracted and grouped into categories.
- [ ] Education and experience are represented in a structured profile.
- [ ] Vacancies are ranked using a documented scoring formula.
- [ ] Each result explains matching and missing skills.
- [ ] Empty and oversized input is handled clearly.
- [ ] Automated tests pass.

## Out of scope
PDF/DOCX parsing, accounts, database persistence, external AI services and automated hiring decisions.
